# 参照画像

原則（[`../principles.md`](../principles.md)）の出どころになった画像です。ブレのあるデザインも含まれており、あくまで参考です。

| ファイル                           | 内容                                                                                             |
| ---------------------------------- | ------------------------------------------------------------------------------------------------ |
| `component-buttons.webp`           | ボタンの見本。Primary、Danger、Gray、Disabled、キャプション付き                                  |
| `component-text-fields.webp`       | テキストフィールドの見本。通常、フォーカス、エラー、パスワード、prefix 付き                      |
| `component-selects.webp`           | セレクトの見本。通常、フォーカス、エラー、prefix 付き                                            |
| `site-works-blog-cards.webp`       | サイトの Works／Blog のカード一覧と More ボタン                                                  |
| `site-profile-mobile.webp`         | k6n.jp のプロフィール画面（モバイル）。キーと値の組（名前の下に、下線付きの値）、Mode の切り替え |
| `site-portfolio-mobile.webp`       | 旧ポートフォリオ（モバイル）。巨大な背景文字、枠線の SNS ボタン、技術タグ                        |
| `color-guideline-2021.webp`        | k6n.jp のカラーガイドライン（Draft 2021.10.12）                                                  |
| `slides-mission-vision-value.webp` | Mission／Vision／Value のスライド                                                                |

構造は、コンポーネント見本の側に寄せます。個性は、Web サイトの側に寄せます。
