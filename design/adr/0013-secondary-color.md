# 0013. ピンクは用途を限定しない Secondary

- ステータス: Accepted
- 日付: 2026-09-12
- ラウンド: 前半 r03 の後（ループ外の確認）

## 背景

これまでの原則6は、色に用途を割り当てていました。

- 「青が『進む』、ピンクが『寄り道』です。ピンクを主要アクションに使わないでください」
- ピンクの用途: More、トグル、装飾見出し

ラウンド2でセクションラベルを水色にしたため（[ADR-0010](./0010-section-label.md)）、「ピンクは More、トグル、Mode の切り替えだけに使う」を確定扱いにして、ユーザーに確認しました。

## 候補

見た目の候補は作っていません。ユーザーへの確認の中で、ピンクの位置づけそのものが示されました。

## 決定

ピンクは、用途を限定しない **Secondary** の色です。Primary（青）と Secondary（ピンク）のどちらを使うかは、その場所に最も合う色を、コンポーネントの利用者が選びます。

旧原則6の次の記述は、この ADR で置き換えます。

- 「青が『進む』、ピンクが『寄り道』」
- 「ピンクを主要アクションに使わないでください」
- ピンクの用途表（More、トグル、装飾見出し）

水色（ブランド）は、これまでどおり見出しとロゴに使う構造の色です。この ADR の対象外です。

## 理由

ユーザーの言葉です。

> ピンクの使いどころは、単に Secondary という立ち位置なので、限定されません。その場所に最も合う色をコンポーネントの利用者が選ぶことになります。

## 却下した案と理由

- **ピンクを More、トグル、Mode の切り替えだけに限定する（確定扱いにしていた案）**: ユーザーの意図と違いました。ピンクは用途で決まる色ではなく、利用者が選ぶ色です

## 影響

- **トークンの名前**: `tokens.css` の役割名を accent から secondary に変えました
  - `--color-secondary`（面用、`#F53273`）: 文字を載せない塗り。トグル ON など
  - `--color-fg-secondary`（前景用、`#E41966`）: 文字、枠線、白文字を載せる塗り。白文字に対して 4.54:1
  - `--color-on-secondary`（白）: Secondary の塗りに載せる文字
  - ラウンド3までの名前は `--color-accent`、`--color-fg-accent`、`--color-on-accent` でした。候補の生成ツールは両方の名前を読めます
- **部品の API**: 色を持つ部品（ボタン、スイッチ、タグ、リンクなど）は、利用者が primary / secondary を選べる形にします。具体的な API は後半で決めます
- **各部品の既定の色**: 利用者が指定しないときに、どちらの色になるかは未決です。後半の軸に追加しました
- **Danger と Secondary の区別の優先度が上がりました**: ピンクの塗りのボタンが、削除ボタン（Danger）の隣に並ぶ場面がありえます。前景用どうし（`#E41966` と `#D4283F`）の比は 1.11:1 しかありません。ユーザーの方向性「Danger はもうちょっと濃くしてもいいかも。」とあわせて、後半の軸で扱います
- `principles.md`: 原則6を書き直しました
