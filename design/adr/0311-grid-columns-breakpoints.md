# 0311. Grid の columns は、画面の幅の段ごとにも渡せる

- ステータス: Accepted
- 日付: 2026-09-24
- ラウンド: ループ外

## 背景

見本の「スマホは 1〜2 列、広い画面は 3〜4 列」の並びを Grid で書くには、画面の幅ごとに列の数を変える口が要ります。幅ごとの列数を持つ場所には、2 つの流儀があります。

| 流儀                           | 例                                                                                                                    |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| 入れ物が、幅ごとの列の数を持つ | Chakra の `SimpleGrid columns={{ base: 1, md: 2 }}`、Mantine の `SimpleGrid cols={{ base: 1, sm: 2 }}`、Radix の Grid |
| 子が、幅ごとの span を持つ     | MUI・Bootstrap                                                                                                        |

見本の 6 ページ（reservation・profile・pricing・dashboard・blog-list・examples）は、どれも同じ幅のカードが並ぶ対称なグリッドで、子ごとに幅を変えたい要望は出ていません。

## 決定

**入れ物側が幅ごとの列の数を持つ流儀にします。`columns` は数のほか、`{ base, sm, md, lg, xl }` の段ごとにも渡せます。**

- 段の名前は Tailwind v4 の既定の画面の幅（sm は 40rem、md は 48rem、lg は 64rem、xl は 80rem）です。base はいちばん狭い画面から
- 渡していない段は、1 つ下の段の数を使います（base もないときは 1 列）
- 入れ子の Grid は、外の Grid の段の数を受け継ぎません
- 画面の幅の段を props で公開する部品は、Grid が初めてです。ほかの部品に広げるかは決めていません（backlog）

## 理由

ユーザーの返事の原文です。

> A の設計でよさそうですね。これで進めてもらえますか？

「A」は、入れ物が段ごとの数を持つ案です。既存の部品の流儀に沿い、対称なグリッドの見本は、子に何も足さずに書けます。子ごとに span を持つ形は、非対称の要望が出たときに、別の部品（backlog の GridItem）として考えます。

## 影響

- `src/components/grid/Grid.tsx`: `columns` が `number | Partial<Record<'base' | 'sm' | 'md' | 'lg' | 'xl', number>>` を受けます。クラスは静的に書き、数だけを style の変数で渡します
- `design/props.md`: 段の名前を語彙に足しました

## 原則への反映

反映なし。原則11の「入力方式で決まるもの、画面の幅で決まるもの、入れ物の幅で決まるものは、それぞれ別です」に沿っています。Grid は、画面の幅（段ごとの `columns`）と入れ物の幅（`minColumnWidth`）の両方で列の数を決められますが、どちらも使う側が選ぶ別々の口で、1 つの判定にはまとめていません。
