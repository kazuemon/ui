# 0425. Tooltip の矢印（showArrow）は 8px、本体とのあいだは 8px

- ステータス: Accepted
- 日付: 2026-10-01
- ラウンド: 後半 軸 462

## 背景

Tooltip に、本体を指す矢印（`showArrow`。既定は出さない）を足しました。Popover の矢印と同じ作りで、面と同じ白に外側の 2 辺だけ輪郭を引いた四角を回します。矢印の大きさと、本体とのあいだを決めました。

## 候補

比較は、決めた時点のコミット `60c0270` の比較のストーリー（`design/stories/axis-462-tooltip-arrow.stories.tsx`）です。列は「下に出す」「上に出す」「押せない理由（フォーカス）」です。

| 案        | 矢印（回す前の一辺）   | 本体とのあいだ |
| --------- | ---------------------- | -------------- |
| 現行版    | なし                   | 8px            |
| A（採用） | 8px（はみ出しは 4px）  | 8px            |
| B         | 12px（はみ出しは 6px） | 10px           |
| C         | 8px（はみ出しは 4px）  | 6px            |

B の矢印は Popover と同じ大きさです。

## 決定

**矢印は 8px、本体とのあいだは 8px にします。** 矢印の先から本体までは 4px です。

- Tooltip の文字（12px）に釣り合う小さな矢印です。本体とのあいだは、矢印のない Tooltip と同じ 8px のままです
- 矢印は既定では出しません（`showArrow` を渡したときだけです）

## 理由

ユーザーの返事の原文です。

> A かなと思いました。ボタンについて props でフォーカス制御を入れていますが、Tooltip で囲まれているなら focusable が伝搬するのが良さそう？と思いました。

この返事の後半は、[ADR-0426](./0426-button-focusable-in-tooltip.md) の決定です。出どころはトリアージの F91 です。

## 却下した案と理由

- **B（Popover と同じ 12px）**: 採りませんでした。小さい面の Tooltip には矢印が大きく見えます
- **C（本体とのあいだを 6px に詰める）**: 採りませんでした。矢印の先が本体から 2px になり、どれの補足かがいちばん近く見えますが、ユーザーは本体とのあいだを矢印のない Tooltip と同じ 8px に保つ A を選びました

## 影響

- `src/components/tooltip/Tooltip.tsx`: `showArrow`（既定 `false`）を持ちます
- 矢印の大きさと本体とのあいだは、部品のトークンの値のままです。比べるためだけの切り替えはありません
- 比較のストーリーは消しました

## 原則への反映

反映なし。矢印の大きさの決定で、原則が新しく扱う対象は増えていません。
