# 0111. シートの引く操作を止める仕組みと、閉じるときの影・× の場所

- ステータス: Accepted
- 日付: 2026-09-18
- ラウンド: ループ外

## 背景

[ADR-0110](./0110-sheet-handle-and-long-press-side.md) で `closeOnSwipe={false}` を足したあと、実機に近い形で触った指摘が続きました。

> スワイプで閉じれない設定にしてもスワイプでドロワーが閉じようとしてしまう（離すと元の位置に戻る）

> スワイプで閉じる瞬間に、離したあと一瞬だけシートの影が下に残るときがありますね

> バツボタンが被ってしまうのがあまり嬉しくないですね。title や description がない場合にも、バツボタン分の領域が上部に確保されるように修正したいです。（Popover 以外は title 必須のはずですが、共通で対策できると嬉しいですね）

あわせて `src/internal/sheet` と、それを使う Dialog・Drawer・Popover を props と挙動のずれの観点で見直し、次が分かりました。

- Base UI 1.8 の Drawer には、はじいて閉じるのを止める prop がない。引く操作は指を置いた時点で始まり、閉じるかどうかは離した時点でしか判定されないので、`onOpenChange` で閉じる合図を取り消しても「引けてしまい、離すと戻る」までしか止められない
- 狭い画面の Dialog は、`dismissible`・`closeOnEscape`・`closeButton` を全部 false にしても、下へ払うと閉じる（Drawer に `closeOnSwipe` を渡していなかった）
- `modal={false}` でも、後ろを暗くする面と面を置く枠が画面全体を覆い、後ろの画面を触れない
- 中央の Dialog は Esc を無視するだけで取り消していない（Drawer は取り消している）
- Dialog・Popover は出し方（シート・浮かべる）ごとに開閉の状態を持っていて、開いたまま出し方が切り替わると（画面を回すなど）閉じる

## 候補

比較のストーリーは作っていません。挙動の直しと、× の場所の 1 通りの直しなので、言葉で決められるためです。

## 決定

| 項目                                                 | 決定                                                                                                                                                                                  |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| はじいて閉じない設定（広げられないとき）             | 面そのものに `data-base-ui-swipe-ignore` を付け、引く操作を始めさせない。面は指に付いてこない                                                                                         |
| はじいて閉じない設定（段があり、上へ広げられるとき） | 引く操作は要るので止めない。下へ引いて離したときの「段を空にする（閉じる）」合図を `onSnapPointChange` で取り消し、いちばん低い段に留める。Base UI は閉じる動きを始めずにその場へ戻す |
| 狭い画面の Dialog のはじく操作                       | 後ろの画面を押して閉じるのと同じ扱いにし、`dismissible` に従う                                                                                                                        |
| `modal={false}` のシート                             | 後ろを暗くせず、面を置く枠は素通しにして、面だけが触れる（Base UI の非モーダルの例と同じ）                                                                                            |
| Esc で閉じない設定                                   | Dialog も Drawer と同じく閉じる合図を取り消す（Base UI が Esc を処理済みにしない）                                                                                                    |
| 出し方の切り替え                                     | Dialog・Popover の開閉は外側の部品で持ち、シートと浮かべる形の両方に渡す                                                                                                              |
| 閉じるときの影                                       | 面の動きと一緒に影も薄くする。はじいて閉じるキーフレームにも同じ消え方を入れる                                                                                                        |
| 題も説明もないシートの ×                             | × を置くときは、題のまとまりに × と同じ最小の高さを持たせ、× が中身に重ならないようにする。Select・Drawer・Dialog・Popover のシートで共通                                             |

## 理由

- **引く操作は始まる前に止める**: Base UI のドキュメントが示す唯一の手段が `data-base-ui-swipe-ignore` です（"opt that element out of swipe dismissal for all input types"）。指を置いた要素から祖先へ探すので、面に付ければ中身全体に効き、中身のスクロールは Base UI が touchmove を素通しするので効いたままです
- **段があるときは合図の取り消しで足りる**: Base UI は段が `null` になる合図が取り消されると、閉じる状態の見た目を付ける前にその場へ戻します。`onOpenChange` で取り消すより早い段階で止まり、閉じる見た目が一瞬付くこともありません。いちばん低い段から下へ引く動きだけは Base UI の仕様上止められず、離すと段に戻ります
- **はじく操作は後ろを押す操作の指の相当**: 「答えるまで閉じたくない」Dialog が、スマートフォンでだけ下へ払うと閉じるのは props に反します。新しい prop を足すより、`dismissible` に従わせるほうが組み合わせを間違えません
- **影が残る理由は緩急の尻尾**: 閉じる動き（250ms、ease-out）では、面は早い段階で画面の端にほぼ着き、外されるまで数フレーム止まっています。その間、面の上端から 32px 上へ伸びる影だけが見えます。はじいたときは離した位置から残りの短い距離を同じ長さで滑るので、止まっている時間が長くなります。Storybook でマウスの引く操作を再現して測った値です

  | 閉じ方                 | 端に着いてから外されるまで |
  | ---------------------- | -------------------------- |
  | はじく（短い中身）     | 72ms                       |
  | はじく（半分の段から） | 54ms                       |
  | ×                      | 20〜36ms                   |

  影を面の動きと一緒に薄くすると、端に着く前に濃さが 0.12 から 0.001 まで落ちます。閉じる動きの長さと緩急（[ADR-0110](./0110-sheet-handle-and-long-press-side.md)）は変えません

- **× の場所は見出しの共通部分で守る**: 題のまとまりの高さは「上下の余白＋題の行」で決めていて、題があるときはちょうど × の高さになります。題も説明もないと余白だけに縮み、絶対配置の × が中身に重なっていました。最小の高さを × と同じにすると、題があるときの見た目は変わらず、ないときだけ × の分が空きます

## 影響

- `src/components/drawer/Drawer.tsx`: `swipeLocked`（はじいて閉じず、広げられもしないとき）を SheetPopup に渡し、`onSnapPointChange` で閉じる合図を取り消す。`modal` も SheetPopup に渡す。`ESCAPE_REASONS` は `src/internal/overlay/close-reasons.ts` へ移した
- `src/internal/sheet/SheetPopup.tsx`: `swipeLocked` で面に `data-base-ui-swipe-ignore` を付ける。`modal={false}` では Backdrop を描かず、Viewport を `pointer-events: none`、面を `auto` にする。閉じる状態で影を消し、`box-shadow` も移り変わりに含める
- `src/styles/theme.css`: `sheet-swipe-out-down` に影の消え方を足した
- `src/internal/sheet/SheetHeader.tsx`: × を置くとき、題のまとまりに `--spacing-control` の最小の高さを持たせる
- `src/components/dialog/Dialog.tsx`: シートに `closeOnSwipe={dismissible}` を渡す。Esc を `cancel()` で取り消す。開閉の状態を外側で持つ。`dismissible` の JSDoc に、シートのはじく操作と、非モーダルでフォーカスが外へ出たときの扱いを足した
- `src/components/popover/Popover.tsx`: 開閉の状態を外側で持つ
- ストーリー: Drawer のストーリーは `modal={false}` をやめてモーダルにした（非モーダルは後ろを暗くしなくなったため。絵は変わらない）。Popover の「文だけ」に `presentation`・`title`・`description` の controls を足し、題のないシートを見られるようにした
- 見た目の基準画像は変えていない
- 分かっていること: 半分の段のときに面へ足している下の余白は、Base UI が測る面の高さを増やし、中身が画面の 50〜85% のとき、面の高さが上限に達するまで数回往復する。上端の位置は保たれるので目には出にくいはずだが、実機で確かめる（backlog）
- 決めていないこと: Popover を題なしでシートに出したとき、dialog に読み上げの名前が付かない。題を必須にするか、名前だけを渡す口を作るかは決めていない（backlog）

## 原則への反映

反映なし。原則11 のつまみの決まり（[ADR-0110](./0110-sheet-handle-and-long-press-side.md)）は変わらず、はじいて閉じない設定でその決まりどおりに面が動かなくなっただけです。
