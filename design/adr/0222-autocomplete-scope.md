# 0222. Autocomplete は、入力した文字が値の別の部品で、選んだときの動きと開く契機を選べる

- ステータス: Accepted
- 日付: 2026-09-21
- ラウンド: 後半

## 背景

Autocomplete は、打った文字に合わせて候補を出す欄です。Combobox（[0214](./0214-combobox-scope.md)）と SearchField に似ているので、どこまでを 1 つの部品にするかを決める必要がありました。あわせて、候補を選んだときの動き、候補を開く契機、Esc・Tab・↓ の扱いを決めました。

## 決定

**Autocomplete は、Combobox・SearchField とは別の部品です。値は入力した文字で、候補は提案です。候補にないものも打てます。**

- Combobox の値は選んだ候補で、Autocomplete の値は打った文字です。フォームには、入力欄の文字を送ります
- SearchField とは別にします。入力欄の見た目（検索風か飾りなしか）は props で選べます（[0224](./0224-autocomplete-input-look.md)）
- 候補を選んだときの動きは 3 つです。既定は、選んだ候補の文字を入力に入れて閉じます（`closeOnSelect` の既定は `true`）。`onSelect(item, event)` で `event.preventDefault()` を呼ぶと、入力・開閉・`onValueChange` を止められます。`closeOnSelect={false}` にすると、入力に入れたまま開いておきます
- 候補を開く契機は `openOn` で、既定は `'input'`（入力したあと）です。`'focus'`・`'click'` も選べます。空にすると閉じます。↓ を押したときは、どれでも開きます
- Esc は、開いていれば閉じるだけで、打った文字は消しません。Tab は動かしません。候補が選択状態を持たないので、選んだ印（チェック）は出しません
- 実行キーは `enterKeyHint`（既定 `'enter'`）で指定できます
- Base UI の Autocomplete は、Root が文字を内部で持つと、`onValueChange` を止めても入力欄が変わります。文字は部品が持ち、Root には制御して渡します
- 候補を上に出す `side` は、今回は入れません。backlog に置きます

## 理由

ユーザーの返事の原文です。

> 入力欄を選べるようにする

> 1-3 全て作りたい。基本は閉じるけど、onSelect で入力をブロックできるようにしたいですね。

> 選択可。デフォルトは入力したあと。空でもサジェストは出す可能性があるので。

以下は、決めたときの考えです。

- **別の部品にする**: 値が入力した文字なのか、選んだ候補なのかで、フォームに送るものも、候補にない文字の扱いも変わります（[原則 18](../principles.md#18-働きで部品を選び見た目は別に選ぶ)）
- **既定は閉じる**: 選んだあとに候補が開いたままだと、次の操作の邪魔になります。開いたままにしたい場面は、`closeOnSelect` で選べます

## 却下した案と理由

- **Combobox に「文字が値」の形を足す**: 値の意味が 2 つになり、フォームの送り方が曖昧になります
- **選んだ候補にチェックを出す**: 候補が選択状態を持たないので出しません。完全一致のときだけ出す形もユーザーが外しました（[0223](./0223-autocomplete-filter.md)）
- **`side`（候補を上に出す）**: [0226](./0226-autocomplete-list-scroll.md) の直しのときに、ユーザーが廃止しました。backlog に置きます

## 影響

- `src/components/autocomplete/Autocomplete.tsx`: 上の props を足しました
- `src/internal/combobox-base/` と `src/internal/listbox/`: Combobox・Autocomplete・TagsInput が使う分を切り出しました（決めた時点のコミット `09b433b`）
- backlog に、`side`（候補を上に出す）と、IME との兼ね合いの確かめを足します

## 原則への反映

原則 8 に、打った文字そのものが値になる欄では、候補は提案で、候補にないものも打てることを足しました。原則 11 に、指の画面キーボードの実行キーを、欄が並んでいても Enter を送るものにすることを足しました。
