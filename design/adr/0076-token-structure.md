# 0076. トークンを尺度・役割・部品に分け、Tailwind の名前空間で公開する

- ステータス: Accepted
- 日付: 2026-09-17
- ラウンド: ループ外

## 背景

[ADR-0003](./0003-token-layers.md) で、色を値の層（`--palette-*`）と役割の層（`--color-*`）に分けました。そのあと後半の軸を決めるうちに、トークンは部品ごとに増え、2026-09-16 の時点で 412 個になっていました。

- 寸法・時間・影には値の層がなく、部品のトークンが生の値を直接持っていました（`1px` が 8 個、`8px` が 8 個、`200ms` が 4 個など）。影の色（`rgb(31 47 55 / …)`）は 7 か所に直書きでした
- タグ・お知らせ・Badge の状態の色は、部品ごとのトークン（`--color-tag-*`・`--color-notice-*`・`--color-badge-*`、合わせて 68 個）が互いを指し合っていました（`--color-badge-info: var(--color-notice-info-filled)`）
- 比べるためだけに足した切り替えのトークン（`0`・`1`・`initial`・`0px` を持つもの）が 37 個ほど残っていました。比較のストーリーを消し、ADR のコミットで再現する運用にしたので、役目を終えていました
- `@theme` と `:root` の分け方に決まりがなく、利用者がどれを使ってよいかが分かりませんでした

ユーザーは、共通の値（角丸の度合いなど）を切り出すことと、Tailwind の定義に乗ることを考えていました。

## 候補

比較の候補はありません。計画（層の分け方、Tailwind への載せ方、進め方）を示し、決めてほしいことに答えてもらいました。

| 項目                         | 示した形                                                                                                   |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 層                           | 値・尺度・役割・部品の4つ                                                                                  |
| 比べるための切り替え         | 消す                                                                                                       |
| 状態の色                     | 状態ごとに役割を置き、タグ・お知らせ・Badge がそれを指す                                                  |
| 公開するもの                 | 値・尺度・役割を `@theme` に置き、Tailwind のクラスで使えるようにする。部品のトークンは公開しない         |
| 場所ごとの色の差し替え       | CSS 変数の上書きではなく、パターンごとの data 属性の入口を用意する                                         |
| 余白と角丸の単位             | px に戻す（Tailwind の既定の rem に乗せたままにする／余白だけ rem、とも比べた）                              |

## 決定

**示した形をすべて採用します。** 場所ごとの色の差し替え（data 属性の入口）は、あとで作ります。

| 項目                   | 決定                                                                                                                                                                                                                                                                                              |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 層                     | 値（`--palette-*`）、尺度（`--spacing`・`--radius-*`・`--border-width-*`・`--duration-*`・`--color-shadow`）、役割（`--color-*`・`--radius-control` など）、部品（`--switch-*`・`--choice-*` など）                                                                                                 |
| 尺度                   | 余白（`--spacing: 4px`）と角丸（`--radius-xs`〜`-4xl`）は、Tailwind と同じ名前・同じ値を px で持つ。線の太さは thin 1px・medium 1.5px・thick 2px、時間は fast 100ms・normal 200ms・slow 250ms。影と後ろを暗くする色は `rgb(from var(--color-shadow) r g b / 濃さ)`。緩急の `--ease-in-out` は Tailwind の既定を使う |
| 状態の色               | 状態（info・success・warning・danger）ごとに、濃い塗り `--color-{状態}`、その上の文字 `--color-on-{状態}`、白地と淡い面の上の文字・線 `--color-fg-{状態}`、淡い面 `--color-{状態}-subtle` の4つ。利用者が選ぶ色にも淡い面と文字（`--color-primary-subtle`・`--color-on-primary-subtle`、secondary も同じ）、色を持たない濃いグレー（`--color-neutral-strong`）を置く |
| 公開と内部             | `@theme` に置いたもの（値・尺度・役割）を公開し、名前を変えない。`:root` は部品の層で、名前も値も予告なく変える                                                                                                                                                                                    |
| 密度で変わる寸法       | Tailwind の名前空間の名前にし（下の表）、`@theme reference` に登録する。利用者は `h-control`・`px-control-x`・`gap-field-gap`・`size-icon`・`text-control`・`text-label`・`text-caption`・`leading-control` を使える。値は `src/styles/globals.css` の密度の規則が入れる                          |
| 部品の中の書き方       | `h-(--spacing-control)` のまま。tailwind-merge が `h-control`・`text-caption` のような名前を知らず、`className` の上書きや色のクラスとの見分けが崩れるため                                                                                                                                         |
| Tailwind の既定のテーマ | このリポジトリ（`globals.css`）では、既定の色と影（`--color-*`・`--shadow-*`）を消す。部品が役割の色と影だけで書かれていることを保つ。利用者に渡すテーマでは消さない                                                                                                                              |
| 比べるための切り替え   | 消し、部品では決まった値に畳む。これからも、比べるためだけに足した切り替えは、決まったら畳む                                                                                                                                                                                                         |

名前を変えたトークン:

| 前                                                  | 後                                                                              |
| --------------------------------------------------- | ------------------------------------------------------------------------------- |
| `--size-control`（`-fine`・`-coarse`・`-coarse-large`） | `--spacing-control`（同じ）                                                     |
| `--space-control-x`（`-fine`・`-coarse`）             | `--spacing-control-x`（同じ）                                                   |
| `--space-field-gap`（`-fine`・`-coarse`）             | `--spacing-field-gap`（同じ）                                                   |
| `--size-icon`（`-fine`・`-coarse`）                   | `--spacing-icon`（同じ）                                                        |
| `--link-grow-duration`・`--link-grow-ease`            | `--link-underline-duration`・`--link-underline-ease`                            |
| `--color-tag-{色}`・`--color-on-tag-{色}`             | `--color-{色}-subtle`・`--color-on-{色}-subtle`（状態の色は `--color-fg-{状態}`） |
| `--color-notice-{状態}-filled`・`--color-badge-{状態}` | `--color-{状態}`                                                                |
| `--color-danger`（文字と線に使うところ）            | `--color-fg-danger`                                                             |

消したトークン（役割と同じ値を指すだけだったもの。部品は役割を直接使う）: `--notice-radius`・`--notice-close-radius`・`--switch-row-radius`・`--choice-frame-radius`・`--select-sheet-radius`、`--switch-row-line-width`・`--choice-frame-line-width`・`--select-popup-line-width`・`--surface-line-width`、`--color-switch-row-line`・`--color-choice-frame-line`・`--color-select-popup`・`--color-select-popup-line`・`--color-select-item-highlight`・`--color-switch-row-hover`、`--color-select-item-reason`・`--color-select-icon-disabled`・`--color-button-caption`・`--color-on-select-item-disabled`・`--color-switch-label-disabled`・`--color-choice-label-disabled`、`--button-caption-gap-*`・`--text-button-caption-*`・`--leading-button-caption`・`--choice-frame-pad-x-*`・`--field-message-icon-size`・`--choice-press-depth`、`--color-badge-ring`・`--color-badge-warning-dot`。

消した切り替えのトークンは、各コミット（下の「影響」）のメッセージに並べました。

## 理由

ユーザーのメモです。最初の依頼です。

> デザイントークンを整理したいです。現在はパーツごとにデザイントークンが定義されていますが、共通で利用できる値（例えば、角丸の度合いなど）などは変数に切り出したりできそうかな？と。あとは tailwind で利用できる定義に乗っかるとかもアリかなと思っています。

部品のトークンを公開するかを尋ねたときの答えです。

> 利用者が tailwind に乗っかって利用できるようにしたい（カラーパレット、角丸の度合い、このコンポーネントの中では変数を上書きして色を反転させる、など）と思っています。完全に内部でしか使うことが無いだろう、というものは無視してもいいと思います。

CSS 変数は宣言した要素で解決されるので、途中の要素で役割を1つ上書きしても、その役割を指している別の役割には伝わりません。そのため、よく使う組み替えは入口を用意する、と示したときの答えです。

> 変数を上書きさせるのではなく、パターンごとに data 属性での切り替えをあらかじめ用意しておくということですね。よさそう。
> 色のばらつきは後からやりましょう。
>
> 1 は消してOK、2もやってOKです。適切な作業単位でコミットをお願いします。
>
> 3 と 4 はあとからでも入れられそう。

（1 は比べるための切り替えを消すこと、2 は状態の色をまとめること、3 は反転などの入口を最初から作るか、4 は色の軸を先に始めるか。）

余白と角丸を Tailwind の既定の尺度（rem）に乗せると、ブラウザの文字の大きさを 16px 以外にしたとき、px の高さと文字はそのままで余白と角丸だけが大きくなる、と伝えたときの答えは「px に戻す」でした。

以下は、メモから読み取れることです。

- **公開するのは、利用者が Tailwind のクラスで使うもの**: 「カラーパレット、角丸の度合い」が挙がったので、値・尺度・役割を `@theme` に置きます。「完全に内部でしか使うことが無いだろう」ものは部品の層に残し、公開の約束をしません
- **色の差し替えは入口で渡す**: 「パターンごとに data 属性での切り替え」なので、利用者に CSS 変数を1つずつ上書きさせる形は公開の使い方にしません（backlog の「色の面（Surface）」と同じ考え）
- **Tailwind に乗るのは名前**: 利用者の `p-2`・`rounded-xl` と部品の値が同じになることは保ちつつ、単位は部品の高さと文字にそろえて px にします

## 却下した案と理由

- **余白と角丸を Tailwind の既定（rem）のままにする**: ブラウザの文字の大きさを変えたとき、余白と角丸だけが大きくなり、端数（6px が 7.5px など）も出ます。rem にするかは、高さと文字と一緒に「全体の倍率」で決めます
- **余白だけ rem にする**: 端数が残ります。角丸と同じ理由で、いまは px にそろえます
- **部品の中も `h-control` などの名前付きのクラスで書く**: tailwind-merge の設定を部品ごとに足す必要があり、足さないと `text-caption` が色のクラスとみなされて消えます
- **部品のトークンを公開する（名前を変えない約束をする）**: 部品の中の都合で変えたい値まで約束することになります。利用者が必要とする差し替えは、役割と data 属性の入口で渡します
- **反転などの入口（data 属性）を今回作る**: 「3 と 4 はあとからでも入れられそう」。backlog の「色の面（Surface）」で作ります

## 影響

- `design/tokens.css`: 412 個から 233 個になりました。先頭のコメントに、層と公開・内部の決まりを書きました
- `src/styles/globals.css`: Tailwind の既定の色と影を消す `@theme` を、tokens.css の読み込みの前に足しました。密度の規則の名前を `--spacing-*` にしました
- 部品: 直書きしていた値（枠線の 1.5px、ノブの影、アイコンとの間の 0.5rem・8px など）をトークンにしました。タグ・Badge・お知らせは状態の役割を直接使い、お知らせは `color` で役割を受け取って `appearance` で割り当てる形にしました。Select の選んだ項目は、面と文字を敷くかの切り替えと、外から色を差し替えるための2段の受け渡しをやめました
- どの段も見た目は変えていません。全ストーリーを撮り、変更の前と画素が一致することを確かめました（16px の画面）
- コミット: `e54ff9d`・`8e94f3a`（切り替えを畳む）、`0d74e14`（尺度）、`cf13f16`（状態の色）、`da70dd6`（別名を消す）、`5ee2c13`（Tailwind の名前空間）、`3486186`（余白と角丸を px に戻す）
- backlog に足したこと: 色のばらつき（パレット）を整える軸、パッケージのテーマに密度の規則を含めること、利用者の tailwind-merge に名前を知らせる設定、尺度に乗らない値、使っていないトークン

## 原則への反映

反映なし。原則はトークンの名前や層を書かない決まりで、見え方も変わっていません。トークンの層と公開・内部の決まりは、`tokens.css` の先頭と CLAUDE.md に書きます。
