# 0435. DropzoneFileList の保存済みのファイルの名前は、url があればリンクにして下線を引く

- ステータス: Accepted
- 日付: 2026-10-01
- ラウンド: 後半 軸 491

## 背景

DropzoneFileList に、保存済みのファイル（サーバーに置いてあるもの）を並べられるようにしました。いま選んだファイルと同じ一覧に並ぶので、どう見分けるかを決めました。

## 候補

比較は、決めた時点のコミット `3f59d4a` の比較のストーリー（`design/stories/axis-491-dropzone-saved-files.stories.tsx`）です。列は「list」「thumbnail」「リンクに hover・フォーカス」です。

| 案                  | 見分け方                                                                     |
| ------------------- | ---------------------------------------------------------------------------- |
| 現行版              | 見分けない。名前はリンクだが、下線も印もない                                 |
| A（採用・印の位置） | 「保存済み」の印と、名前の薄い下線                                           |
| B（採用）           | 名前の薄い下線だけ                                                           |
| C                   | 保存済みの行は塗らずに細い枠だけにし、いま選んだものを塗る。A の印と下線つき |

## 決定

**保存済みの名前は、url があればリンクにして、いつも薄い下線を引きます（B の形）。** 行の塗りや輪郭で見分ける C は採りません。印の扱いは [ADR-0436](./0436-dropzone-file-caption.md) です。

- 下線のあるなしが、保存済み（リンクになる）といま選んだもの（リンクにならない）の見分けになります
- 下線は hover で濃くなります。リンクの決まり（原則 3）のとおりです

## 理由

ユーザーの返事の原文です。

> 491 キャプションは 保存済み・保存日時を任意に入れるなど、自由に設定できると良さそうです。リンクなら下線を引く、は原則通りとします。

## 却下した案と理由

- 現行版: 下線がないと、保存済みの名前が押せるように見えません。
- C: 行の塗りや輪郭を変えると、押せない状態や選択の状態の見た目とぶつかり、一覧が重くなります。

## 影響

- `src/components/dropzone/DropzoneFileList.tsx`: リンクの名前にいつも下線を引きます
- 見分け方を比べるためだけに置いたトークン（印の表示、リンクの下線、保存済みの面と枠の色）は、実装のコミット `e46af66` で消しました
- 比較のストーリーは消しました

## 原則への反映

反映なし。リンクには淡い下線を引くという原則 3 のとおりです。経緯の ADR に足しました。
