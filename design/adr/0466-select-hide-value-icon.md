# 0466. Select の選んだ値の欄にアイコンを出さない形を、hideValueIcon で選べる

- ステータス: Accepted
- 日付: 2026-10-02
- ラウンド: 後半 軸 523（トリアージ F10）

## 背景

選択肢にアイコンを足したとき（[ADR-0465](./0465-listbox-item-icon.md)）、Select の本体（選んだ値の欄）にも、選んだ項目のアイコンを出すかが分かれました。開いた一覧の中だけにアイコンを置き、本体はほかの入力欄と同じラベルだけに見せたい場面があります。

## 決定

**既定では、本体の選んだ値の前にもアイコンを出します。** `hideValueIcon` を指定すると、本体にはアイコンを出さず、開いた一覧の中だけにします（比較の D の性質）。

Combobox の本体は文字を打つ欄なので、選んだ値の前にアイコンは出せません。

## 理由

ユーザーの返事の原文です（[ADR-0465](./0465-listbox-item-icon.md) と同じ返事です）。

> C デフォルトで、アイコンを選択表示に出さないオプションも欲しいですね。

## 却下した案と理由

- 既定を出さない形にする: 選んだ値の前のアイコンは、何を選んだかを文字より早く伝えます。出すほうを既定にしました

## 影響

- `src/components/select/Select.tsx`: `hideValueIcon`（既定は出す）。比べるためのトークン（`--select-value-icon-display`）は畳みました

## 原則への反映

反映なし。既定と選べる形（[原則 20](../principles.md#20-部品は知らないことを決めない)）の範囲内です。
