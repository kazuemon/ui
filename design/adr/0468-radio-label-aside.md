# 0468. カードの形の Radio に labelAside。カード全体を押せて、フォーカスの線はカードを囲む

- ステータス: Accepted
- 日付: 2026-10-02
- ラウンド: 後半 軸 524（トリアージ F13）

## 背景

プランの選択では、選択肢の名前の右に値段を置きます。いまの Radio は、題（label）と説明（caption）しか持たず、値段は caption に書くしかありませんでした。

## 決定

**Radio に `labelAside` を足します。** ラベルの行の右端に置く文です（値段など）。カードの形（frame="card"）の Radio で使います。

- カード全体が押せます。押せる範囲は見た目の範囲です（[原則 17](../principles.md#17-押せる範囲は見た目の範囲)）
- キーボードのフォーカスの線は、丸ではなくカードを囲みます
- 面・輪郭・角・hover の塗りは Card と同じです。読み取り専用のカードは、載せても塗りを変えません（[原則 13](../principles.md#13-押せないものは浮かせず薄くする)）
- `labelAside` は、選択肢の名前には入れず、説明として読み上げます（caption の前に読みます）。値段は選ぶときの材料になるためです
- 説明の中に置いたリンクやボタンは、カードの押せる範囲より上に出し、マウスでもそのまま押せるようにします。カードのほかの場所を押すと選ばれます

## 理由

[ADR-0467](./0467-radio-card-selected.md) の比較（軸 524）を作る前に、カードの形の組み立てとして実装していたものを、比較の中で見て残しました。比較の時点では返事の原文はありません。

レビュー（2026-10-04）で、0467 に畳まずにこの ADR を残すこと、値段を読み上げに入れること、カードの中のリンクを押せるようにすること、読み取り専用で載せた塗りを外すことを、まとめて「お勧めで」と返事をもらいました。

## 却下した案と理由

- caption に値段を書く: 説明の行に混ざり、右端にそろいません

## 影響

- `src/components/radio/Radio.tsx`: `labelAside`。説明（Base UI の Field.Description）として描き、読み上げに入れます
- `src/internal/choice/choice-styles.ts`: カードの中のリンク・ボタンを押せる範囲より上に出すこと、読み取り専用で hover の塗りを付けないこと

## 原則への反映

反映なし。押せる範囲（原則 17）とフォーカスの線（[原則 2](../principles.md#2-フォーカスとエラーは枠線で表す)）の範囲内です。
