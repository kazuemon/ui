# 0138. Calendar の月送りの置き方

- ステータス: Accepted
- 日付: 2026-09-19
- ラウンド: 後半 軸110

## 背景

月を送るボタン（‹ ›）と月の名前をどう並べるかを決めます。月を送るボタンは、アイコンだけの枠線のボタンです（いちばん進めたい操作ではないため、原則 7）。

## 候補

| 案     | 内容                                                                                               |
| ------ | -------------------------------------------------------------------------------------------------- |
| 現行版 | 両側に置く。前の月を左、次の月を右に置き、月の名前を中央に置く。押す向きと送る向きが一致する       |
| A      | 右にまとめる。月の名前を左に寄せ、送るボタンを右にまとめる。見出しを左から読め、2 つのボタンが近い |

状態は、グレー・前へ送れないときの 2 列で比べました。

## 決定

**現行版（両側に置く）を既定にし、A（右にまとめる）も選べるようにしました。**

## 理由

ユーザーの返事の原文です。

> 110: 両側デフォルト、右も選べるで。

- 両側に置く現行版は、押す向きと月が送られる向きが一致するので、初めて見ても迷いにくい形です
- 右にまとめる A は、2 つのボタンが近く、続けて送るときの指やマウスの移動が少ないという利点があるため、選べる形として残しました

## 却下した案と理由

却下した案はありません。両案とも採用しました（現行版を既定、A を選択可能に）。

## 影響

- `src/components/calendar/Calendar.tsx`: `navPlacement`（`sides` | `end`）props を足しました。既定は `sides`（両側）で、`navPlacement="end"` で右にまとめる見た目に切り替えられます
- `design/tokens.css`: 比較用に置いていた `--calendar-head-columns`・`--calendar-caption-order`・`--calendar-prev-order`・`--calendar-caption-align` は、`navPlacement` の値ごとの並びに畳み込んで削除しました
- backlog に足す未決事項: 年と月を直接選ぶ機能（月の名前を Select 2 つに替える、または月の一覧に切り替える）は、いまの月送りとは別の入力手段として backlog に残します（[design/backlog.md](../backlog.md)）。ユーザーからは「年と月を直接編集できるようにしたい気持ちもありますが、今は適した Input がなさそうですかね（作って後から実装でも可）」という返事がありました

## 原則への反映

反映なし（既存の原則の範囲内）。月送りのボタンの置き方は、枠線のボタンの並べ方（原則 7）の範囲内の決定です。
