# 0168. 入力欄の suffix に入れるのは、値に作用するものだけ

- ステータス: Accepted
- 日付: 2026-09-19
- ラウンド: ループ外

## 背景

[ADR-0035](./0035-field-addon.md) は「suffix に入れるボタンは、入力欄そのものを操作するもの（パスワードの表示・非表示など）に限る。検索のように入力した内容を送るボタンは、入力欄の外に置く」と決めました。原則の整理（[ADR-0164](./0164-principles-reorganization.md)）で、この線引きを言い直す必要が出ました。原則 8 は「止めているあいだも suffix のボタンは押せる。suffix のボタンは値を変えないため」と書いていましたが、入力した内容を消すボタンは値を変えます。

## 候補

| 案     | 内容                                                                                           |
| ------ | ---------------------------------------------------------------------------------------------- |
| 現行版 | 「欄そのものを操作するもの」。止めているあいだも suffix のボタンは押せる                       |
| A      | 「欄の値に作用するもの」。値を変える suffix は欄と一緒に止め、見え方だけを変えるものは止めない |

## 決定

**A にします。**

- suffix に入れるボタンは、欄の値に作用するものだけです。伏せ字の切り替えや、入力した内容の消去がそうです
- 検索のように実行するものは、値とは関係がないので、欄の外に色か枠線のボタンとして置きます（ADR-0035 のまま）
- 欄を止めているあいだ（[ADR-0042](./0042-field-loading.md)）は、値を変える suffix（消去）を欄と一緒に止めます。見え方だけを変える suffix（伏せ字の切り替え）は止めません

## 理由

ユーザーの返事の原文です。

> 入力欄の suffix になりうるのは、値に対して影響を与えるものであるべきかなと思います（パスワードの伏せ字切り替え、入力内容の削除など。）検索ボタンは実行するものなので、値に関係ないものとして切り離したいです。

止めるのは「値を変えるもの」という決まり（[ADR-0059](./0059-form-submitting.md)）と同じ線で、suffix のボタンも分けられます。

## 却下した案と理由

- **現行版**: 「欄そのものを操作する」では、消去のボタンを止めるかどうかが決まりませんでした

## 影響

- 部品の変更はありません。消去のボタンはまだ作っていません。作るときに、止めているあいだ一緒に止まることを確かめます（backlog に足しました）
- ADR-0035 の決定は変わりません。線引きの言い方を直しただけです

## 原則への反映

原則 8 の suffix の行を「欄の値に作用するものだけ」に書き換えました。止めるものの決まりは、原則 14 に「止めるのは、値を変えるものだけ。見え方だけを変えるものは止めない」と書いています。
