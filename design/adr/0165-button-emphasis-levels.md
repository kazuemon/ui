# 0165. 押すものの強さは 3 段（色の塗り・グレーの塗り・枠線）

- ステータス: Accepted
- 日付: 2026-09-19
- ラウンド: ループ外

## 背景

原則 7 は「画面で最も進めたい操作は塗り、それ以外は枠線」と書いていました。一方で、色を指定しない塗りのボタンはグレーの塗りになります（[ADR-0028](./0028-default-color.md)）。グレーの塗りのボタンをいつ使うかは、どこにも書かれていませんでした。原則の整理（[ADR-0164](./0164-principles-reorganization.md)）の問い D12 です。

## 候補

| 案  | 内容                                                                                    |
| --- | --------------------------------------------------------------------------------------- |
| a   | 強さを 3 段として書く。色の塗り（最も進めたい操作）、グレーの塗り（ふつうの操作）、枠線 |
| b   | 2 段のまま、グレーは「色を決めていない塗り」とする。塗りか枠線かだけが強さ              |
| c   | 使い分けは決めず、backlog に足す                                                        |

## 決定

**a にします。** 押すものの強さは 3 段です。色の塗りは画面で最も進めたい操作、グレーの塗りはふつうの操作、枠線は控えめにしたい操作と密度の高い並びに使います。

## 理由

隣に並べたとき、実際にこの順に強く見えるためです。ユーザーは台帳で a を選びました（メモなし）。

## 却下した案と理由

- **b**: 選ばれませんでした。グレーの塗りと色の塗りが並ぶと強さの差として読まれるので、「色を決めていないだけ」という説明は見え方と合いません
- **c**: 選ばれませんでした

## 影響

- 部品とトークンの変更はありません。いまの見た目の使い分けを言葉にした決定です
- グレーの欄のすぐ横にグレーの塗りのボタンを置かない決まり（[ADR-0035](./0035-field-addon.md)）は、そのままです

## 原則への反映

原則 7 の考えの文を、3 段の説明に書き換えました。

画像はありません。使い分けの決定で、見た目の比較をしていないためです。
