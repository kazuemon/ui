# 0099. 後半ラウンド（本文の部品）で据え置きにしたこと

- ステータス: Accepted
- 日付: 2026-09-17
- ラウンド: 後半（PR #9 のあと）

## 背景

軸51〜56（読む文字の大きさ・文中のコード・キー・引用・記事の中の囲み・アイコンの大きさ）が一段落したところで、残っていた小さな確認を3つまとめて尋ねました。ほかの ADR（軸ごとの決定）に入らない、据え置き・現状維持の判断をここに記録します。

同じときに出た「脚注の戻る印を文字の ↩ からアイコンにする」件は、脚注そのものの決定（[ADR-0089](./0089-footnote.md)）に含めており、ここには含めません。

## 候補

比較の候補はありません。3つの問いへの答えを尋ね、それぞれ「据え置き（いまのままにする）」か「利用者にゆだねる」かを決めた記録です。

## 決定

| 項目                                             | 扱い                                                                                         |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| 見出し（Heading）の途中での折り返し              | 部品では設定を持たない。`Heading` から `text-balance` を外し、利用者が `className` で付ける  |
| トグル・チェックボックス・ラジオの箱の大きさ     | 据え置き。入力方式（密度）で変わる、いまの形のまま                                           |
| 読みもの（`data-reading`）の中のアイコンの大きさ | 据え置き。指で操作していても 16px 前後（密度どおり）のまま、読む文字のような入れ替えはしない |

## 理由

ユーザーのメモです。

> 1: 利用者にゆだねることにします（こっちでは設定を付けない）
> 2: 一旦このままでよさそうです
> 3: 16px のままにします。枠に囲まれていないのと、前後に文字が並ぶからです。

- **見出しの折り返しは利用者にゆだねる**: 見出しが自動で改行される位置に違和感がある、という話から `text-wrap: balance` や `word-break: auto-phrase`、BudouX のような分かち書きを検討しましたが、`auto-phrase` は Chrome だけの対応で `lang="ja"` が要ること、Storybook は `lang="en"` で確かめられないことなどから、部品では決めず「利用者にゆだる」ことにしました。`Heading` が既定で持っていた `text-balance` も外しました。原則9（遊びはレイアウト層に置く）の考え方（装飾やレイアウト判断は部品の外）に沿います
- **トグル・チェックボックスの箱の大きさは現状維持**: 部品の文字や高さ・余白は軸51・軸79（[ADR-0079](./0079-control-type-and-height.md)）で入力方式によらず同じにしましたが、トグルのトラックとチェックボックス・ラジオの箱はまだ密度で大きさが変わります。「一旦このままでよさそうです」との返事どおり、いまは変えません
- **読みものの中のアイコンは 16px のまま**: 読む文字（本文）は `data-reading` の中では指でもマウス用の大きさ（16px）を保ちます（軸51、[ADR-0078](./0078-reading-type.md)）が、アイコン（`--spacing-icon`）にはこの入れ替えを足しませんでした。理由は「枠に囲まれていないのと、前後に文字が並ぶから」です。部品（ボタンなど）のアイコンは枠の中に収まり単独で意味を持ちますが、記事の中のアイコン（引用や囲みの先頭のアイコンなど）は前後に文章が続く並びの一部であり、文字ほど厳密に大きさをそろえる必要がないと判断しました。結果として、指＋読みものの組み合わせでは、本文が 16px、アイコンは密度どおりの 16px（`--spacing-icon-coarse`）になり、値がたまたま一致します

## 却下した案と理由

却下した案はありません。ここでの決定は、いずれも「いま手を付けない」「利用者にゆだねる」を選んだことです。

## 影響

- `src/components/heading/Heading.tsx`: `text-balance` を外しました。折り返し方は使う側が `className` で指定します
- `design/backlog.md`: 「見出しの途中での折り返し」（[ADR-0078](./0078-reading-type.md) で足した項目）と、「トグルのトラック・チェックボックスの箱が入力方式で変わる」（[ADR-0079](./0079-control-type-and-height.md) で足した項目）は、この ADR で決着したため消してください
- `design/backlog.md` に足す未決事項の案: なし。3項目とも「このままでよい」という決定であり、新たに調べることは残っていません

## 原則への反映

原則9 の文を書き換えました（すでに適用済み）。「見出しの折り返し方も、部品では決めません。使う側が文章に合わせて選びます。」を足しました。トグル・チェックボックスの箱の大きさと、読みものの中のアイコンの大きさについては反映なし（既存の原則の範囲内）です。
