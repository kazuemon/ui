# 0371. Fieldset の見出しは本文の大きさの太字が既定。大きさは Heading の段で選べる

- ステータス: Accepted
- 日付: 2026-09-29
- ラウンド: 後半 軸 390

## 背景

Fieldset の見出し（「住所」「配送」）と、中の欄のラベル（「郵便番号」「配送方法」）の差の付け方を決めます。中に RadioGroup を置くと見出しが 2 段になるため、重さの釣り合いも見ます。

## 候補

比較は、決めた時点のコミット `5132b4b` の比較のストーリー（`design/stories/axis-390-fieldset-legend.stories.tsx`）です。列は、入力欄のまとまり・選択肢のまとまり、の 2 つです。

| 案                               | 文字                                   |
| -------------------------------- | -------------------------------------- |
| 現行版（本文の太字。採用・既定） | 本文の大きさ・太字・本文の色           |
| A（ラベルと同じ）                | 中の欄のラベルと同じ（太字）           |
| B（見出し 3）                    | 見出し 3 の大きさ・太字                |
| C（小さく淡い）                  | キャプションの大きさ・太字・一段淡い色 |

## 決定

**既定は現行版（本文の大きさの太字）のままにします。** 中の欄のラベルより一段強い見出しです。

- 見出しの大きさは `labelSize?: HeadingSize`（既定 `'md'`）で、Heading の `size` と同じ段（ADR-0368・0369）から選べます。`md` は本文と同じ大きさで、どの段でも太字です

## 理由

ユーザーの返事の原文です。

> 390 デフォルトは本文文字と同じで、今 typography-adjust agent がやっている文字サイズの段を指定できるようにしたいですね。

> セクションの見出しサイズ指定については typography-adjust agent がやっている形に合わせたいと考えています。

## 却下した案と理由

- **A（ラベルと同じ）**・**C（小さく淡い）**: 既定には採りませんでした。どちらも中の欄のラベルより弱いか同じ重さになる案で、段の指定（`labelSize`）でも選べません
- **B（見出し 3）**: 既定には採りませんでした。同じ大きさは `labelSize="lg"` で選べます

## 影響

- 既定の見た目は現行版のままです。Fieldset に `labelSize` を足しました。見出しのクラス列は Heading と同じもの（`src/internal/reading/heading.ts`）を使います
- 比較のストーリーは消しました
