# 0447. Calendar の日ごとの印は、日の下の中央に小さい文字で置く。印を持つ日がある月は、すべての日の数字を上へずらす

- ステータス: Accepted
- 日付: 2026-10-01
- ラウンド: 後半 軸 471

## 背景

Calendar に足した日ごとの印（`renderDayContent`。空きのある日の点、残りの数、値段など）の置き場・文字の大きさ・数字のずらし方と、今日の下線の位置を決めました。

## 候補

比較は、決めた時点のコミット `f8758ca` の比較のストーリー（`design/stories/axis-471-calendar-day-content.stories.tsx`）です。列は「点の印」「文字の印」「期間の中」です。

| 案        | 印の置き場と数字                                                                                               |
| --------- | -------------------------------------------------------------------------------------------------------------- |
| 現行版    | 印なし（比べるための基準）                                                                                     |
| A         | 数字の下の中央・10px の文字。印のある日の数字だけ上へずらす。今日の下線は印の下に残る                          |
| B         | 数字の下の中央・12px（キャプション）。数字をさらに上へずらす                                                   |
| C         | 日の右上の角。数字は動かさない                                                                                 |
| E（採用） | A の置き場。印を持つ日がある月は、印のない日も含めてすべての日の数字を上へずらす。今日の下線は数字と印のあいだ |

## 決定

**E を採用します。** 印は日のボタンの下の中央に、小さい文字（点も含む）で置きます。印を持つ日がある月は、印のない日も含めて、すべての日の数字を印の分だけ上へずらし、横で数字の高さをそろえます。今日の下線は、数字と印のあいだに引きます。印のない月の今日の下線は、今のまま（日のボタンの下）です。

- 印が付く日と付かない日で、数字の高さがばらつきません
- 今日の下線は、印があってもなくても数字に付く飾りとして読めます

## 理由

ユーザーの返事の原文です。

> 文字や点が付くときは、全体として下に点や文字の余白が入り、横で数字が揃うのが良いなと思いました。また、今日を表す印は常に数字と付加要素の間に来ると良さそうです。

最初の返事です。これを受けて E を足しました。E を見たあとの返事です。

> E でよさそう。今日のマークについてはバックログに追加して、見直し対象とさせてください。

## 却下した案と理由

A（印のある日だけずらす）は横で数字がそろいません。B は日の中が詰まり、今日の下線が印に重なります。C は角の印が数字から離れ、どの日の印か読みにくくなります。

## 影響

- `src/components/calendar/Calendar.tsx`: `renderDayContent`（日を受け取り、印を返す）。印を持つ日がある月だけ、すべての日の数字をずらします
- `design/tokens.css`: `--calendar-day-content-bottom`・`--calendar-day-content-text`・`--calendar-day-number-shift`・`--calendar-today-mark-offset`
- 今日の下線の位置と形は見直す対象です（backlog）

## 原則への反映

反映なし。日ごとの印の置き場の決定で、原則の文を変える対象は増えていません。
