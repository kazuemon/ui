# 0113. トグルの押下は :active ではなく pointer イベントで持つ

- ステータス: Accepted
- 日付: 2026-09-18
- ラウンド: ループ外

## 背景

トグルの色のちらつき（[ADR-0112](./0112-fill-transition-by-registered-property.md)）を調べる途中で、タッチでも別の余計な動きが見つかりました。

トグルのノブは、トラックやラベルを押しているあいだ少し縮みます（[ADR-0067](./0067-switch-row-press.md)）。これを CSS の `:active`（トラックの `:active`、行の `:has(label:active)`）で付けていました。Chrome はタッチで速く押すと、スクロールと区別するために `:active` を指を置いた瞬間には付けず、離したあと（click の直後）に 100〜150ms だけ付けます。付くかどうかは押し方で変わります（Storybook でタッチを再現して 5 回押すと、2 回だけ付きました）。トグルは離した瞬間に切り替わるので、ノブが滑り始めてから縮み、130ms ほどして戻ります。行を囲む形（`frame`）では、行の塗りも離したあとに付いてすぐ消えます。

フレームごとにトラックの中の白いピクセル（ノブ）を数えた値です（`components-switch--playground`、タッチ、DPR 3）。

| 場面                   | 直す前                                     | 直したあと                            |
| ---------------------- | ------------------------------------------ | ------------------------------------- |
| 指を置いているあいだ   | 483 のまま（縮まない）                     | 483 → 421（縮む）                     |
| 離して切り替わったあと | 474 → 420 のまま 130ms → 483（縮んで戻る） | 436 → 474（戻りながら滑る。縮まない） |

マウスでは `:active` が押している間だけ付くので、この動きは出ません。

## 候補

比較のストーリーは作っていません。ノブの縮み方と行の塗り（ADR-0067）は変えず、それを付けるきっかけを変えるだけなので、言葉で決められるためです。

## 決定

| 項目                   | 決定                                                                                                                                                               |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 押しているあいだの検知 | `:active` をやめ、行の `pointerdown` から `pointerup`・`pointercancel`・`pointerleave` までを部品が state で持つ                                                   |
| 印の置き場所           | トラックに `data-pressing` を付ける。ノブの縮みは `group-data-pressing/switch`、行の塗りは `has-data-pressing` で見る                                              |
| 印の名前               | `data-pressing`。Base UI は `data-pressed` を Toggle や Popover.Trigger の「ON・開いている」（続く状態）に使うので、置いているあいだ（一時の状態）は別の名前にする |
| 押下にする範囲         | ラベルとトラック（`frame` ではラベルの `::after` が行いっぱい）。列の隙間は押しても切り替わらないので押下にしない。押せないとき・送信中は押下にしない              |

## 理由

- **pointerdown は指を置いた瞬間に来る**: Chrome のタッチの `:active` はスクロールと区別するために遅れ、速く押すと離したあとに回ります。`pointerdown` は touchstart と同時に来るので、押しているあいだだけ縮み、離した瞬間に戻りながら滑ります。マウスの見え方は変わりません
- **CSS の切り替えのトークンでは表せない**: `:active` の付く時点はブラウザが決めるので、tokens.css の上書きでは直せません。部品の中の小さなフック（`use-pressed.ts`）で持ちます。2 つ目の部品が使うときに `src/internal/` へ移します
- **見た目は変えない**: 縮む倍率・長さ・緩急、行の塗りと 0ms の入りは ADR-0067 のままです。見た目の基準画像も変わっていません

## 影響

- `src/components/switch/use-pressed.ts`: 押しているあいだを pointer イベントで持つフック。押せる要素（`label`・`[role="switch"]`）の中で主ボタンを置いたときだけ押下にする
- `src/components/switch/Switch.tsx`: 行に `usePressed` の handlers、トラックに `data-pressing`。`group-active/switch`・`group-has-[label:active]/toggle` を `group-data-pressing/switch` に、行の `active:` を `has-data-pressing:` に置き換えた。root の `group/toggle` は要らなくなったので外した
- `src/components/switch/Switch.stories.tsx`: 「状態」の押下の列は、pseudo-states の `active` ではなく `data-pressing` を渡して作る
- 見た目の基準画像は変えていない
- 分かっていること: チェックボックス・ラジオの押下（`--choice-press`、[ADR-0063](./0063-choice-press.md)）とボタンの沈み（`active:`）も `:active` で付けているので、タッチでは同じように離したあとに一瞬付くことがある。backlog に置く

## 原則への反映

反映なし。押しているあいだの見え方（原則1・ADR-0067）は変わらず、タッチでもそのとおりに見えるようにしただけです。
