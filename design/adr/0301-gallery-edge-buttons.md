# 0301. Gallery の端でも、前後のボタンは押せない見た目で残す

- ステータス: Accepted
- 日付: 2026-09-23
- ラウンド: 後半（軸外。軸 285〜299 の返事の中で決まりました）

## 背景

Gallery も Carousel と同じく、端の画像（最初・最後）では前後のどちらかへ送れません。軸 291（[ADR-0289](./0289-gallery-controls-position.md)）の比較のストーリーでは、列の 1 つに「端では前へ送るボタンを出さない」という注記を残したままでしたが、実際にどちらの見た目にするかは別に確かめました。

## 候補

| 案                                            | 内容                                                 |
| --------------------------------------------- | ---------------------------------------------------- |
| 押せない見た目で残す（採用。Carousel と同じ） | ボタンの位置は動かず、端にいることがボタンでも分かる |
| 消す                                          | 送れないボタンはそもそも出さない。位置は縮む         |

## 決定

**Gallery も、Carousel（[ADR-0287](./0287-carousel-edge-buttons.md)）と同じく、送る先がない端では、前後のボタンを消さずに押せない見た目で残します。押せなくなったボタンからはブラウザがフォーカスを外すので、反対のボタンへ移します。**

## 理由

ユーザーの返事の原文です（「そろえる」の一部として答えています）。

> 端のボタンはGalleryも押せない見た目で残す

Pagination の前へ・次へ（[ADR-0177](./0177-pagination-current.md)）、Carousel の前へ・次へ（[ADR-0287](./0287-carousel-edge-buttons.md)）と同じ考え方です。ボタンを消すと、送っている途中で位置がずれたり、押せる範囲が急に変わったりします。押せない見た目のまま残すことで、原則13（押せないものは、浮かせず薄くする）の形にそろい、部品をまたいで同じ振る舞いになります。

## 影響

- `src/components/gallery/GalleryControls.tsx`: `hasPrev`・`hasNext` が `false` のとき、ボタンを `disabled` にし、フォーカスを反対のボタンへ移します

## 原則への反映

反映なし。原則13（押せないものは、浮かせず薄くする）の範囲内です。
