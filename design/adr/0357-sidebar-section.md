# 0357. Sidebar の題は SidebarSection にし、列は複数の節に分けられる

- ステータス: Accepted
- 日付: 2026-09-24
- ラウンド: Sidebar の実装を見てもらった直し

## 背景

はじめは、列そのものが 1 つの題（`title`）を持ち、開いた列の上端に固定して出していました（[ADR-0356](./0356-sidebar-padding-scroll.md)）。この題は、スクロールしない場所に置いていたので、列の中身と一緒にはスクロールせず、狭い画面の Drawer にも出ませんでした。列を節に分ける形もありませんでした。

## 候補

比較のストーリーは作っていません。実装を見てもらい、直しの指示を受けました。

| 案        | 内容                                                                                                                                |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| A         | 列そのものが 1 つの題を持ち、上端に固定する。Drawer には出さない                                                                    |
| B（採用） | 題は `SidebarSection` の題にする。列の中は `SidebarSection` を何個でも並べられ、各節の題は中身と一緒にスクロールし、Drawer にも出す |

## 決定

**列の題は `Sidebar` の `title` ではなく、`SidebarSection` の `title` にします。`SidebarSection` は列の中に何個でも置けます。節の題は、開いた列でも Drawer でも、行と同じスクロールする場所に出ます。畳んだ列（rail）では、節の題を出さず、代わりに節のあいだに区切り線を引きます。列そのものの読み上げの名前と、狭い画面の Drawer の題は、`Sidebar` の `drawerLabel`（既定 `'メニュー'`）にします。**

## 理由

ユーザーの返事の原文です。

> 試合管理というセクションタイトルは、スクロールの対象に含める かつ ドロワーでも表示されてほしいです。
> また、セクションは複数作成できるのが望ましいと思いました。
> 代わりに drawerLabel を設定できるようにするとよいと思います。

「試合管理」は、列の中の 1 つのまとまりの名前であって、列そのものの名前ではありません。列の名前（読み上げ・Drawer の題）と、中のまとまりの見出しは別の役割なので、別の props に分けます。まとまりが複数あるからこそ見出しが要るので、`SidebarSection` を繰り返し置ける形にします。

畳んだ列は、行がアイコンだけになり、節の題を出す場所がありません。節のあいだは区切り線で示し、節の名前は畳んだままでも読み上げの一覧の名前として残します（`aria-label`）。

その後（2026-09-29）、畳むと題の分だけ行が上にずれることが気になったため、畳んだ列でも題と同じ高さの場所を残し、区切り線はその縦の真ん中に引くようにしました。開いた列と畳んだ列で、行の縦の位置がそろいます。

## 影響

- `src/components/sidebar/`: `Sidebar` から `title` を外し、`drawerLabel` を持たせます。新しく `SidebarSection`（`title`）を公開します。行（`SidebarItem`）は `SidebarSection` の中に置きます
- 見本（`Overview/見本`「試合管理」）は、`SidebarSection` を 2 つ（「試合管理」「関連情報」）に分けます
