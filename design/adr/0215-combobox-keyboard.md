# 0215. Combobox のキーボードは、消去を Tab で止め、Esc は閉じるだけにする

- ステータス: Accepted
- 日付: 2026-09-21
- ラウンド: 後半

## 背景

文字を打つ Combobox は、キーボードと日本語入力（IME）の動きが Select より多く、決めることがありました。消去の × に Tab で止まるか、Esc で何を消すか、打った文字と選んだ値の関係、最初の項目を自動で選ぶかどうかです。

## 決定

**消去の × は Tab で止めます。Esc は閉じるだけで、独自の消去は付けません。**

- 消去の × は Tab で止まります。SearchField と揃えます
- Esc は選択肢を閉じるだけです。閉じると、打った文字は選んだ値のラベルに戻ります（Base UI の動き）
- `autoHighlight` の既定は `false`（Base UI の既定）です。打っただけでは最初の項目を選びません
- 日本語入力は、Base UI の変換中の処理に任せます。変換中の Esc は奪いません
- `inputValue` は、呼び出し側が渡したときだけ Base UI に渡します。制御すると、単数選択で選んだ値のラベルを入力欄に写す同期が止まるためです
- 打っただけで選んでいないときは、消去の × を出しません（SearchField は打った文字だけでも出します）

## 理由

ユーザーの選択の原文です。

> 止める（SearchField と揃える） (Recommended)

> 単一選択では消さない。打った文字だけを消す (Recommended)

> false（Base UI の既定） (Recommended)

以下は、決めたときの考えです。

- **Esc の消去を付けない**: 閉じているときの Esc で選んだ値まで消すかを尋ね、「打った文字だけを消す」と答えをもらいました。そのあとで、閉じれば打った文字は元に戻ると分かり、独自のハンドラは要らないので外しました
- **消去は値に作用するもの**: × は入力した内容を消すボタンで、欄の端に置く条件（[0168](./0168-field-suffix-acts-on-value.md)・[0190](./0190-field-addon-kinds.md)）のとおりです。押せる場所なので、Tab で止めます
- **Base UI の既定に任せる**: `autoHighlight`・変換中の Esc は、Base UI の既定が使う側の予想と合います

## 却下した案と理由

- **Esc で選んだ値まで消す**: 選ばれませんでした。単数選択の値を、閉じる操作のついでに消すと、意図しない消え方になります
- **消去の × を Tab で飛ばす**: 選ばれませんでした。SearchField と同じ扱いに揃えました

## 影響

- `src/components/combobox/Combobox.tsx`: `autoHighlight`（@default `false`）を足しました。`inputValue` は、渡されたときだけ Base UI に渡します
- `src/components/combobox/Combobox.stories.tsx`: キーボード・日本語入力・消去の確かめを `play` に書きます
- トークンの追加はありません
- backlog に、複数選択の欄で先頭にいるときの ← でチップへ移ることを読み上げで伝える文（`aria-description` の prop）と、変換中に ← でチップへ移る余地（実機で確かめる）を足します

## 原則への反映

反映なし。欄の中のボタンを Tab で止めること・Esc・自動で選ぶ印・IME は、原則 15 の「キーボードの振る舞いは働きに従います」の範囲内で、部品ごとの決まりは部品のドキュメントに属します。
