# 0268. Embed の読み込み中は、回る円を出さず光の帯を動かしたまま

- ステータス: Accepted
- 日付: 2026-09-23
- ラウンド: 後半 軸 274

## 背景

Embed をクリックしたあと、iframe の読み込みが終わるまでの見た目を決めました。

## 候補

比較は、決めた時点のコミット `9944d66` の比較のストーリー（`design/stories/axis-274-embed-loading.stories.tsx`）です。外部と通信しない `data:` URL の中に、わざと 1.2 秒の待ちを入れて確かめました。

| 案     | 内容                                                                              |
| ------ | --------------------------------------------------------------------------------- |
| 現行版 | 回る円を出し、光の帯は止める。「進んでいる」ことを 1 つの動きだけに絞る（原則14） |
| A      | 回る円は出さず、光の帯のまま。ボタンからスピナーへの切り替えがない分、静か        |
| B      | 回る円を出し、光の帯も動いたまま。進んでいることは強く伝わるが、動きが 2 つ重なる |

## 決定

**A（回る円は出さず、光の帯は動いたまま）を既定にします。**

加えて、読み込み中は既定で「読み込み中」の文言を出すことになりました（`loadingText`。`children` を渡していなければ、部品がここで文言を足します）。

## 理由

ユーザーの返事の原文です。

> 274: A でお願いしたいですが、デフォルトで読み込み中である文言も表示したいです。

A は変化が少なく静かですが、クリックが効いたのかが分かりにくいおそれがあったため、文言（`loadingText`、既定「読み込み中」）を足すことで補いました。B は動きが賑やかになりすぎるため採りませんでした。

## 却下した案と理由

- **現行版（回る円を出す）**: 選ばれませんでした。クリックという能動的な操作のあとに動きを切り替える案でしたが、A のほうが静かで、文言で「進んでいる」ことを補えると判断しました
- **B（回る円＋光の帯、両方動く）**: 選ばれませんでした。動きが 2 つ重なり賑やかになりすぎます

## 影響

- `src/components/embed/Embed.tsx`: `--embed-loading-spinner-display: none`・`--embed-loading-motion-play-state: running` にしました。`loadingText` props（既定「読み込み中」）を足し、`children` がなければ読み込み中の面にこの文言を出します
- `design/tokens.css`: `--embed-loading-spinner-display`・`--embed-loading-motion-play-state` を追加しました
- 比較のストーリー `design/stories/axis-274-embed-loading.stories.tsx` は消しました

## 原則への反映

反映なし。原則14（動きは手応えと待ちを伝える）の「待っているあいだは、結果がないことを知らせません」「止めない形では、回る印を足すだけで、操作は続けられます」の範囲内です。まだ何も求めていない面（idle）は動かさない、という新しい一文は [ADR-0265](./0265-embed-idle-face.md) に書きました。
