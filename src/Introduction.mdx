# @kazuemon/ui

コンポーネントがいっぱいあるけど、マテリアルデザインほどかたい感じじゃないモダンなUIライブラリを目指して制作しています。

## フォント

英数字と日本語で、フォントを混ぜて使います。

- 英数字: [Mulish](https://fonts.google.com/specimen/Mulish)
- 日本語: [IBM Plex Sans JP](https://fonts.google.com/specimen/IBM+Plex+Sans+JP)
- 等幅（コードなど）: [Geist Mono](https://fonts.google.com/specimen/Geist+Mono)
